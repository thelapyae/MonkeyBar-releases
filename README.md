# MonkeyBar for macOS

A quiet network monitor and a dropdown shelf for hidden menu bar apps.

**[Website](https://monkeybar.thelapyae.com) · [Download the latest release](https://github.com/thelapyae/MonkeyBar-releases/releases/latest) · [Support](https://github.com/thelapyae/MonkeyBar-releases/issues)**

This repository contains release notes and downloadable app bundles. Application source code is maintained separately and is not published here.

## Requirements

- Apple Silicon Mac (M1 or newer)
- macOS 14 or later
- Accessibility permission for the hidden-app shelf; network monitoring needs no permission

## Install

1. Download the ZIP from Releases and unzip it.
2. Move MonkeyBar.app into Applications and open it.
3. Click the grid icon for hidden apps; click the separate speeds for network details.
4. Choose Arrange menu bar icons, then Command-drag unwanted icons left of the divider. Keep both MonkeyBar controls to its right. Click the grid icon to finish.

## Notes

Early release. macOS menu-bar layout, notched screens and some system or third-party items have limitations. Rates include local interface traffic and are not a billing meter. No per-app network tracking, packet capture, analytics or account is included. CPU/energy savings compared with other apps have not been benchmarked.

## Privacy

Network counters and menu-item data are processed on your Mac. No app telemetry is sent to us. See the [privacy policy](https://monkeybar.thelapyae.com/privacy.html).
